# SESRL 任务管理改编版

## 原量表信息

- **全称**：Self-Efficacy for Self-Regulated Learning Scale (SESRL)
- **出处**：Zimmerman, B. J., Bandura, A., & Martinez-Pons, M. (1992). Self-motivation for academic attainment: The role of self-efficacy beliefs and personal goal setting. *American Educational Research Journal*, 29(3), 663-676.
- **理论基础**：Bandura (1997) 自我效能理论 + Zimmerman 自我调节学习三阶段模型（前瞻 Forethought / 执行 Performance / 反思 Self-reflection）
- **原量表**：11 题，7 点 Likert（1 = 完全不能，7 = 完全能）
- **改编后**：9 题（保留 7 题 + 新增 2 题），7 点 Likert（1 = 完全没有信心，7 = 非常有信心）

---

## 改编原则

1. 保留原有构念（自我调节效能感），将学业语境替换为日常任务管理语境
2. 删除无法合理改编到任务管理场景的学术特定技能题目
3. 补充原量表在 Zimmerman 反思阶段的覆盖不足
4. 所有改编题目保持"我有信心能……"的自我效能表述结构

---

## 保留并改编的题目（7 题）

### 第 1 题

| | 内容 |
|---|---|
| **原题** | How well can you finish homework assignments by deadlines? |
| **改编** | 我有信心能在自己设定的时间内完成当天的任务 |
| **阶段** | 前瞻（Forethought） |
| **理由** | 截止时间管理是任务管理核心能力。将"作业截止日期"改为"自己设定的时间"更符合日常任务管理场景——参与者使用 MetaPlan 自主规划每日任务，时间约束来自自我设定而非外部作业要求。 |

### 第 2 题

| | 内容 |
|---|---|
| **原题** | How well can you study when there are other interesting things to do? |
| **改编** | 当有其他更有趣的事情诱惑时，我有信心能坚持做当前的任务 |
| **阶段** | 执行（Performance） |
| **理由** | 抗干扰能力对 ADHD 群体极其相关，是执行功能困难的核心表现之一。构念完全保留，仅将"学习"改为"做当前的任务"。 |

### 第 3 题

| | 内容 |
|---|---|
| **原题** | How well can you concentrate on school subjects during class? |
| **改编** | 做任务时，我有信心能保持专注不走神 |
| **阶段** | 执行（Performance） |
| **理由** | 专注维持能力的构念不变。将"课堂上集中注意力于学科内容"改为"做任务时保持专注"，对应参与者使用 MetaPlan 专注计时的实际场景。 |

### 第 4 题

| | 内容 |
|---|---|
| **原题** | How well can you plan your schoolwork for the day? |
| **改编** | 我有信心能合理规划每天要做的事情 |
| **阶段** | 前瞻（Forethought） |
| **理由** | 日常计划能力直接对应原型的任务列表和第一步脚手架功能。将"学业任务"改为"每天要做的事情"扩展到更广的日常任务管理语境。 |

### 第 5 题

| | 内容 |
|---|---|
| **原题** | How well can you organize your schoolwork? |
| **改编** | 我有信心能把一个复杂的事情拆成具体可执行的步骤 |
| **阶段** | 前瞻（Forethought） |
| **理由** | 原题"组织学业"过于宽泛。改为"拆解为可执行步骤"更具体地对应任务管理中的核心技能，也直接映射原型中将大任务拆为子任务和微步骤的设计理念。 |

### 第 6 题

| | 内容 |
|---|---|
| **原题** | How well can you arrange a place to study without distractions? |
| **改编** | 我有信心能为自己创造一个不容易被打断的工作环境 |
| **阶段** | 执行（Performance） |
| **理由** | 环境管理对 ADHD 用户是重要的自我调节策略。将"学习场所"改为"工作环境"，从学校/图书馆语境扩展到参与者日常办公/宿舍等任务管理场景。 |

### 第 7 题

| | 内容 |
|---|---|
| **原题** | How well can you motivate yourself to do schoolwork? |
| **改编** | 当我不想做任务时，我有信心能让自己开始行动 |
| **阶段** | 执行（Performance） |
| **理由** | 启动困难（initiation deficit）是 ADHD 最典型的挑战之一。原题测量的是自我激励能力，改编后更精确地聚焦于"从不想做到开始行动"的启动过程，也直接对应原型中"第一步"脚手架的设计意图。 |

## 删除的题目（4 题）

### 原第 4 题

| | 内容 |
|---|---|
| **原题** | How well can you take class notes of class instruction? |
| **删除理由** | 课堂笔记是特定的学术技能（信息记录与整理），属于学习策略而非自我调节过程。无法合理改编为任务管理语境中的自我效能题目。 |

### 原第 5 题

| | 内容 |
|---|---|
| **原题** | How well can you use the library to get information for class assignments? |
| **删除理由** | 图书馆信息检索是特定的学术资源利用技能。在日常任务管理语境中没有直接对应的行为，强行改编会偏离原有构念。 |

### 原第 8 题

| | 内容 |
|---|---|
| **原题** | How well can you remember information presented in class and textbooks? |
| **删除理由** | 学术内容的记忆能力属于认知能力（cognitive ability），而非自我调节效能感（self-regulatory self-efficacy）。与任务管理中的自我调节过程不在同一构念维度。 |

### 原第 11 题

| | 内容 |
|---|---|
| **原题** | How well can you participate in class discussions? |
| **删除理由** | 课堂讨论参与是社交互动行为，与个人任务管理的自我调节无关。无法在任务管理语境中找到对应构念。 |

## 新增的题目（2 题）

### 第 8 题（新增）

| | 内容 |
|---|---|
| **新增** | 完成任务后，我有信心能客观评估自己今天的表现和效率 |
| **阶段** | 反思（Self-reflection） |
| **理由** | 对应 Zimmerman (2000) 反思阶段中的 **self-judgment**（自我评价）子过程。原版 SESRL 11 题中几乎没有覆盖反思阶段的题目——这是原量表的已知局限。本研究的原型包含每日反思功能（数据可视化 + AI 对话），测量参与者对自我评估能力的效能感是必要的。 |

### 第 9 题（新增）

| | 内容 |
|---|---|
| **新增** | 当原来的做法不管用时，我有信心能调整策略换个方式继续 |
| **阶段** | 反思（Self-reflection） |
| **理由** | 对应 Zimmerman (2000) 反思阶段中的 **adaptive/defensive reactions**（适应性反应）子过程。策略调整能力对 ADHD 群体尤为重要：面对卡住时能否灵活切换而非僵化坚持或直接放弃。也直接对应原型中"卡住 → 获取 AI 建议 → 继续任务"的功能设计。 |

## 论文中的写法建议

> We adapted the Self-Efficacy for Self-Regulated Learning scale (SESRL; Zimmerman, Bandura & Martinez-Pons, 1992) to the task management context. Four items specific to academic skills (note-taking, library use, content memorization, and class participation) were removed as they could not be meaningfully adapted to daily task management while preserving the original self-regulatory construct. Two items addressing self-evaluation and adaptive strategy adjustment were added to ensure coverage of Zimmerman's (2000) self-reflection phase, which was underrepresented in the original scale. The final adapted scale contained 9 items rated on a 7-point Likert scale, organized across three self-regulatory phases: forethought (3 items), performance (4 items), and self-reflection (2 items). Internal consistency was acceptable (Cronbach's α = X.XX).
