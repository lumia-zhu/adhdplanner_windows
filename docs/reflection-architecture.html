Figure X. System architecture of the AI-powered reflection dialogue. Behavioral data from task events and computer activity is aggregated by a summarizer into a daily behavioral summary. This summary, along with historical reflection memory, is injected into a system prompt that also encodes an empathetic conversational role, ADHD-sensitive dialogue constraints, and metacognitive reflection instructions targeting four awareness dimensions (task, self, strategy, and behavioral pattern). During the multi-turn conversation, the LLM presents personalized data insights while the user reflects at their own pace, guided by suggested exploration directions. After each session, key insights and user commitments are automatically extracted and fed back into the memory store, enriching future reflection conversations.
